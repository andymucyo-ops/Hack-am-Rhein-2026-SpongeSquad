    Contribute

    Replace a placeholder tomorrow

    Each workstream owns its folder. The website only links stable entry points.

    Run the site

    npm start

    Installs missing dependencies, builds every module and serves the site at http://localhost:4173/. After editing only shell pages or docs, run npm run build:shell and reload.

    Replace your page

    1. Edit your folder's index.html, for example explainer-videos-context/index.html. Keep the header and footer slots and the script tags.
    2. Put assets such as videos or images next to it and list them in the build if they need copying.
    3. Change your workstream's status in integration/routes.json.
    4. A new app is added under modules in the same file.

    Keep the evidence honest

    • Label values as observed, derived, assumed, illustrative or unknown.
    • Never turn an area score into street geometry, soil or drainage values.
    • Unknown never silently becomes good, zero or safe.
    • State a Basel procedure only with a Basel source.
